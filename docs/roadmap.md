# Roadmap

## Done

- Function calling with verified tool results (41+ tools)
- Safe self-modification with AST + pyflakes + runtime test + rollback
- Bidirectional voice (STT with fallback, TTS with markdown stripping)
- Reactive energy orb driven by emotion, activity and audio pulse
- Persistent memory, diary and long-conversation summarization
- Dynamic skill registry (skills created at runtime)
- Autonomy: sensors, limbic state, planner and task queue
- Local IoT control (Tuya) with scenes
- Five-layer local protection system

## Next

- Screen understanding with explicit measurement before any visual claim
- Better long-horizon planning with cost/risk estimation per step
- Multi-provider LLM routing by task type (cheap model for chat, strong model for code)
- Packaged installer with first-run setup wizard
- Public demo video and reproducible benchmark of tool-calling reliability

## Non-goals

- Being a general chatbot — the value is *acting* on the machine, not chatting
- Cloud dependency — every core capability must work locally
- Claiming capabilities that cannot be verified
